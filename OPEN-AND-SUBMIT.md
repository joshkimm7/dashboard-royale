# The Gilded Ace submission files

1. **Interactive dashboard.** Attach `gilded-ace.html` as the dashboard file. Judges download it and open it in a modern browser such as Chrome with JavaScript enabled. It embeds the data and works without an account, internet connection, or local server. Use the full file for submission.
2. **Write-up.** Paste the body of `DEVPOST-WRITEUP.md` into the Devpost project description.
3. **Walkthrough.** Add your own video of two minutes or less. Show the interactive dashboard and explain the cost, status, and tradeoffs of the inspection, deferred relocation, and conditional promotion.
4. **Code and transformations.** Link the public GitHub repository or attach this package. `dashboard.html` is the interface and analysis template. `build_data.py` prepares the data and holdout. `README.md` pins the official data release and shows the build commands.
5. **Claims and evidence.** Attach `CLAIMS-AND-EVIDENCE.md` or link to it on GitHub. It includes the AI-use disclosure and identifies the sources, calculations, alternative explanations and limitations.
6. **Submission preview.** Confirm your dashboard attachment or publicly accessible URL opens when signed out. Check the video visibility and duration, then submit through Devpost.

The July decision funds one catalog action. Two priced alternatives are separately labeled deferred and conditional. No hosted owner-view link is required to run the attached dashboard.
